# CLAUDE.md

ScrollCapture is a macOS 27 menu-bar agent (`LSUIElement`, Swift 6). **⌃⌥⌘S** screenshots the window under the mouse, scrolls it down with synthetic wheel events until it stops moving, stitches the frames and puts a PNG on the clipboard (or in the system screenshot folder when "Zapisuj do pliku" is on). Pressing the hotkey again cancels a running capture.

## Commands

The Xcode project is generated by XcodeGen and git-ignored; edit `project.yml`.

```bash
scripts/build.sh         # Debug build
scripts/run.sh           # build, kill the previous Debug instance, launch
scripts/test.sh          # offline tests (--adhoc: no "Local Self-Signed" certificate needed)
```

`xcodebuild` fails inside the Claude Code sandbox; run it with `dangerouslyDisableSandbox: true`. SourceKit errors before a build are noise.

## How it works

- `Sources/ScrollCapturer.swift`: picks the topmost layer-0 window under the cursor (`CGWindowListCopyWindowInfo`, front-to-back), captures it with `SCScreenshotManager` (`desktopIndependentWindow` filter), posts `CGEvent` pixel-unit scroll events at the cursor (half the window height per step), waits 350 ms, captures again.
- `Sources/Stitcher.swift` (pure, tested): the first moving pair fixes the scrolling band (rows/columns that changed) so static headers, footers and sidebars are left out of matching; the right 20 pt of the band are ignored because overlay scroller thumbs move. Rows are hashed; the shift is the `dy` with ≥90 % matching rows closest to the expected scroll distance. Shift 0 = end of page.
- Permissions: Accessibility (posting events) and Screen Recording. Signed with the shared `Local Self-Signed` identity so TCC grants survive rebuilds.
- Icons (`Sources/Assets.xcassets`): Tabler `arrow-autofit-down` in white on a teal `#0E9F8E` squircle, plus a template menu-bar glyph — the same style as Glosso's icons.
- The user verifies the UI by hand; don't drive the app with Computer Use.

## Reference: how Shottr 1.9.3b does it (static evidence only)

From imports, ObjC/Swift metadata and strings of the stripped binary (`Shottr-1.9.3b.dmg`, git-ignored; no decompiler was available):
`ScrollCapturer` class (`grabScrolling(direction:method:then:)`, ivars `screenshotInterval`, `noShiftTimeout`, `lastShiftDetectedTime`, `shifts`, `nilShifts`, `stitchedScreenshot`), scrolling via `CGEventCreateScrollWheelEvent2` + `CGEventPost` (Accessibility required, "reverse direction" setting for MOS/Scroll Reverser users, speed slider, max-height limit), capture via `SCScreenshotManager` / `CGWindowListCreateImage` / `CGDisplayStream`. Shift detection: custom `findShift(shots:lastCapture:step:…)`, `shiftPixels(img:tpl:maxShift:)`, `shiftGradient(…)` template matching, plus a `VisionStitcher` using `VNTranslationalImageRegistrationRequest`; joining via `combine(shots:region:direction:stripeHeight:…)`, `overlayCompareSegment` and `overlayShiftStamp` fallbacks. Shottr stitches a user-selected area; this app uses the window under the cursor instead.
